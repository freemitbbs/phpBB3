# Top Stats Extension 3.2.x

## Install

1. Download the latest release.
2. Unzip the downloaded release, and change the name of the folder to `topstats`.
3. In the `ext` directory of your phpBB board, create a new directory named `stoker` (if it does not already exist).
4. Copy the `topstats` folder to `/ext/stoker/` (if done correctly, you'll have the main extension class at (your forum root)/ext/stoker/topstats/composer.json).
5. Navigate in the ACP to `Customise -> Manage extensions`.
6. Look for `Top Stats` under the Disabled Extensions list, and click its `Enable` link.

## Uninstall

1. Navigate in the ACP to `Customise -> Extension Management -> Extensions`.
2. Look for `Top Stats` under the Enabled Extensions list, and click its `Disable` link.
3. To permanently uninstall, click `Delete Data` and then delete the `/ext/stoker/topstats` folder.
