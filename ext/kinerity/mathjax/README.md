## Description
This extension based on MathJax v3.2.2 technology.
MathJax is an open-source JavaScript display engine for LaTeX, MathML, and AsciiMath notation that works in all modern browsers.
This extension does not connect to external servers to start the MathJax display engine.

The extension creates BBCode with which formulas can be generated using LaTeX. With these BBCodes, the formulas can be displayed inline or in a separate paragraph.

## Installation
Copy the extension to `phpBB/ext/kinerity/mathjax`

Go to "ACP" > "Customise" > "Extensions" and enable the "MathJax" extension.
